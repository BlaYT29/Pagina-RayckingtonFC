# Rayckington FC — Sitio Web Oficial

Sitio web oficial de **Rayckington FC**, desarrollado para centralizar la información deportiva, institucional y comunicacional del club.

El proyecto permite gestionar y mostrar información sobre el plantel, partidos, competiciones, noticias, galería, patrocinadores y distintas actividades del club mediante una estructura dinámica basada en archivos JSON.

---

## Rayckington FC

**Rayckington FC** es un club de fútbol fundado en 2025.

El proyecto nació con el objetivo de construir un club basado en el compromiso, la organización, la competencia y la pasión por el fútbol.

**Lema oficial:**

> Nacimos para competir, jugamos para ganar.

---

## Sitio web

Dominio oficial:

**https://rayckingtonfc.cl**

El sitio está preparado para ser publicado mediante **GitHub Pages**, utilizando el dominio oficial registrado en NIC Chile y administración DNS mediante Cloudflare.

---

## Tecnologías utilizadas

El sitio fue desarrollado utilizando:

- HTML5
- CSS3
- JavaScript
- JSON
- Git
- GitHub
- GitHub Pages

No utiliza frameworks ni sistemas de gestión de contenido externos.

---

## Sistema dinámico

La información principal del sitio se administra mediante archivos JSON, permitiendo actualizar contenido sin modificar directamente la estructura HTML.

Entre los contenidos administrables se encuentran:

- Plantel
- Jugadores
- Partidos
- Resultados
- Competiciones
- Estadísticas
- Noticias
- Galería
- Patrocinadores
- Temporadas deportivas
